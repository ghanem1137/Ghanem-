# ويكند سعيد ☀️

نشرة أسبوعية تفاعلية لموظفي المكتب، تنزل كل نهاية أسبوع وتخلي الويكند يبدأ برواق.

## وش فيها؟

| القسم | الفكرة |
|---|---|
| ⚽ مباريات الويكند | أقوى 4 مباريات (الدوري السعودي والعالمي) يوم الجمعة والسبت |
| 🔮 توقّع وخلّك شجاع | استطلاع على إحدى المباريات، والنتيجة تظهر مباشرة بعد التصويت |
| 💡 توصية من زميل | مطعم، كافيه، فيلم، كتاب… باسم الزميل ("قهوة الجمعة برأي زميلنا فلان")، والكتاب له رابط تحميل + QR |
| 📸 عدسة الموظف | الموظفين يرفعون صور الويكند، والفريق يختار "صورة العدد" |
| ✍️ ركن إبداع الزملاء | مقالة، بودكاست، أو قصيدة من الزملاء |
| 🌱 طوّر نفسك على رواق | مقالات قصيرة لتطوير الذات |
| 🧩 مسابقة الويكند السريعة | سؤال خفيف (معالم جازان أو لغز) + QR للإجابة من الجوال + سحب عشوائي على الفائز |
| 📮 صندوق المشاركات | استقبال الاقتراحات والمشاركات للعدد الجاي |

**إضافات مقترحة:** عدّاد تنازلي للويكند، شريط مناسبات الزملاء (ترحيب، تهنئة، عيد ميلاد، ترقية)، واقتباس الأسبوع.

وكل قسم فيه ❤️ إعجاب و💬 تعليقات، والتحديث يوصل للكل مباشرة بدون إعادة تحميل الصفحة.

## التشغيل

يحتاج فقط **Node.js 18 أو أحدث**، بدون أي مكتبات إضافية:

```bash
ADMIN_PASSWORD=كلمة-سر-قوية npm start
```

- صفحة الموظفين: `http://localhost:3000`
- لوحة فريق النشرة: `http://localhost:3000/admin`

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `PORT` | `3000` | منفذ الخادم |
| `ADMIN_PASSWORD` | `weekend123` | كلمة مرور لوحة الإدارة — **غيّرها قبل النشر** |

البيانات تنحفظ في `data/db.json` والصور في `data/uploads/`. خذ نسخة احتياطية من مجلد `data` بشكل دوري.

## دورة العدد الأسبوعية (لفريق النشرة)

1. **📰 العدد:** غيّر رقم العدد والتاريخ وكلمة الترحيب.
2. **⚽ المباريات:** حدّث الأربع مباريات.
3. **🔮 الاستطلاع:** اختر مباراة بضغطة زر (الأصوات تتصفّر تلقائياً لما تتغير الفرق).
4. **💡 التوصيات / ✍️ الإبداع / 🌱 تطوير الذات / 🎉 المناسبات:** أضف أو عدّل المحتوى (غالباً من مشاركات الصندوق).
5. **📸 عدسة الموظف:** اعتمد الصور، واختر "صورة العدد".
6. **🧩 المسابقة:** اكتب السؤال والإجابات المقبولة. وقت الإعلان اضغط "سحب الفائز" (المقارنة تتجاهل التشكيل والهمزات والتاء المربوطة).
7. **📮 الصندوق:** راجع المشاركات وعلّم على اللي تم استخدامه.

## ملاحظات

- الموظف ما يحتاج تسجيل دخول: يكتب اسمه مرة وحدة والمتصفح يتذكره، والتصويت مرة وحدة لكل جهاز.
- الصور تتصغّر تلقائياً قبل الرفع، ولا تظهر للجميع إلا بعد اعتمادها من الإدارة.
- مكتبة QR مضمّنة محلياً (`public/vendor/qrcode.js` — MIT) فتشتغل حتى بدون إنترنت.
